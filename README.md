# Zahl des Tages

Erzeuge eine Zahl des Tages per Zufallsgenerator - mit Timer für Kopfrechenphase.

## Erzeugung

Benötigte Tools:
* irgendeine Shell (unter Windows sollte Git-Bash funktionieren - ungetestet!)
* npm mit npx

Elm Code kompilieren:

```sh
    npm install
    npm run make
```
Nach dem Kompilieren liegt die gesamte App im Ordner `/www`.
